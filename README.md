# GSAP Slider

Static Webflow export hosted on GitHub Pages.

Live demo: https://Yevhen-2012.github.io/gsap-slider/

## Development

Serve this directory with any static HTTP server. No build step is needed.

## Deployment

GitHub Pages publishes the root directory of the main branch.

Images, Webflow runtime, jQuery, GSAP, and WebFont Loader are included locally. Google Fonts remains an external dependency.

The original layout, typography, and slider interactions are preserved from the supplied Webflow export.
